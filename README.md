# Project Iron Hand v1.0.0

## Overview

Project Iron Hand is an AI-powered cyber incident investigation platform designed to analyze digital forensic artifacts and generate structured security assessments.

The system consists of multiple machine learning modules that process memory dumps, operating system artifacts, and investigation findings to identify suspicious activity, evaluate evidence quality, detect unsupported conclusions, and generate human-readable investigation reports.

The primary goal of Project Iron Hand is to assist security analysts during incident response and forensic investigations by providing automated evidence validation and narrative generation.

---

## Problem

Modern forensic investigations produce large amounts of data from memory dumps, system logs, process listings, network artifacts, and command histories.

Security analysts often spend significant time:

* Reviewing evidence manually
* Validating investigation hypotheses
* Detecting contradictory findings
* Writing investigation reports

Project Iron Hand automates these tasks using machine learning and large language models.

---

## Architecture

The platform is divided into independent components.

### ML1 — Evidence Analysis Engine

Responsibilities:

* Parse memory analysis artifacts
* Process Linux forensic data
* Extract behavioral indicators
* Calculate anomaly scores
* Generate investigation findings

Input sources:

* Process lists
* Network connections
* Loaded kernel modules
* Bash history
* Memory artifacts
* System logs

Output:

* Structured findings
* Confidence scores
* Investigation hypotheses

---

### ML2 — Doubt Engine

Responsibilities:

* Verify generated conclusions
* Detect unsupported claims
* Challenge assumptions
* Measure hallucination risk
* Generate final investigation narratives

Core modules:

#### Devil Advocate

Challenges conclusions generated by previous stages and attempts to identify alternative explanations.

#### Grounding Verification

Validates whether conclusions are supported by available evidence.

#### Natural Language Inference (NLI)

Classifies relationships between findings and evidence.

Possible outcomes:

* Entailment
* Neutral
* Contradiction

#### Semantic Similarity

Measures semantic consistency between findings and supporting evidence.

#### Hallucination Detection

Calculates hallucination probability using outputs from all verification modules.

#### Narrative Generator

Creates a human-readable forensic report.

---

## Data Flow

1. Digital forensic artifacts are collected.
2. ML1 extracts indicators and generates findings.
3. Findings are passed to ML2.
4. Devil Advocate challenges conclusions.
5. Grounding Verification validates evidence.
6. NLI checks logical consistency.
7. Semantic Similarity evaluates relevance.
8. Hallucination Detection calculates reliability.
9. Narrative Generator creates the final report.
